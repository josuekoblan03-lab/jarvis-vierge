# Fiche formateur — S3 : Continuité parfaite

**Objectif :** l'apprenant maîtrise la continuité (PROGRESS, NEXT_SESSION, `/reprendre`), initialise son projet avec `/nouveau-projet`, et lance le squelette Next.js.

---

## Déroulé (2 h)

### 0-10 min — Retour devoir
- Il intègre ses 3 ajustements de spec. Rapide.

### 10-35 min — Concept : ne jamais perdre le fil
- Le vrai problème : une conversation Claude a une limite. Quand elle sature, on perd le contexte. Le débutant recommence tout à chaque fois.
- La solution : **tout ce qui a de la valeur va dans un fichier**, pas dans la conversation.
- Les 4 fichiers d'un projet : CLAUDE.md (constitution), PROGRESS.md (où on en est), DECISIONS.md (pourquoi tel choix), NEXT_SESSION.md (prompt pour repartir).
- `/reprendre` = relire ces fichiers et repartir en 30 secondes dans une conversation neuve.
- Démo : ouvrir un PROGRESS.md réel, montrer comme on comprend l'état du projet en 10 secondes.

### 35-50 min — Démo : `/nouveau-projet`
- Montrer la séquence : `/nouveau-projet` pose 3 questions (nom, description, stack), crée les 4 fichiers + met à jour INDEX.md, puis propose un plan AVANT de coder.
- Insister : aucun code n'est écrit tant que la structure n'est pas là et le plan validé.

### 50 min-1 h 50 — Pratique
1. L'apprenant lance `/nouveau-projet` pour son app (à partir de sa spec de S2).
2. Il répond aux 3 questions. Stack : Next.js + Supabase + Vercel.
3. Claude crée `projects/<son-app>/` avec les 4 fichiers. L'apprenant les ouvre et les lit.
4. Claude propose un plan d'attaque. L'apprenant le valide.
5. Première étape du plan : créer le squelette Next.js. Laisser Claude le faire, l'apprenant regarde la sortie et lance `npm run dev` pour voir la page par défaut dans le navigateur.
6. Commit.

### 1 h 50-2 h — Récap + checkpoint + devoir
- `/reprendre` blanc : fermer, rouvrir, taper `/reprendre`, vérifier que Claude retrouve tout. Effet « waouh » garanti.
- **Devoir** : ouvrir une NOUVELLE conversation demain et reprendre son projet seul avec `/reprendre`. Noter si ça marche.

---

## Points de vigilance
- C'est LA séance qui change tout pour lui. Prendre le temps sur le « pourquoi ».
- S'assurer que `npm run dev` tourne (port occupé, Node manquant → dépanner).
- **Économie Pro** : marteler que `/reprendre` dans une conversation neuve coûte BEAUCOUP moins qu'une conversation de 3 h qui traîne. C'est le réflexe-clé de l'abonnement Pro.

## Démo possible sur un vrai projet
Montrer ton INDEX.md avec plusieurs projets : « je peux jongler entre eux sans rien perdre ».

## Critère de réussite
L'apprenant ferme tout, rouvre, tape `/reprendre` et son projet repart intact.

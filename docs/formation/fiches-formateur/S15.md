# Fiche formateur — S15 : Déploiement

**Objectif :** l'app est EN LIGNE sur Vercel, avec ses variables d'environnement en production. L'apprenant comprend previews et déploiement.

**Pré-requis :** compte Vercel (gratuit) + code sur un repo GitHub.

---

## Déroulé (2 h)

### 0-10 min — Retour devoir
- Historique git vérifié, aucune clé. Si une clé traîne : on traite en priorité (régénérer la clé chez le fournisseur).

### 10-35 min — Concept : passer du local au monde
- En local, seul moi vois l'app (`npm run dev`). Déployer = la rendre accessible par une URL publique.
- **Vercel** : hébergement fait pour Next.js, gratuit pour démarrer, se connecte au repo GitHub.
- **Variables d'environnement en prod** : mes clés (.env local) doivent être recopiées dans Vercel, PAS commitées. L'app en prod lit celles de Vercel.
- **Preview** : chaque changement crée une URL de test avant la prod.
- Démo : montrer un projet déployé et son dashboard Vercel.

### 35-50 min — Démo : premier déploiement
- Pousser le code sur GitHub, importer le projet dans Vercel, configurer les variables d'env, lancer le déploiement, ouvrir l'URL publique.

### 50 min-1 h 50 — Pratique
1. L'apprenant pousse son app sur un repo GitHub (privé).
2. Il importe le projet dans Vercel.
3. Il reporte ses variables d'environnement (Supabase, etc.) dans les réglages Vercel (jamais dans le code).
4. Il déclenche le déploiement, puis ouvre son app sur l'URL publique.
5. Il teste le parcours complet en ligne : inscription, connexion, données.
6. PROGRESS.md + DECISIONS.md + commit.

### 1 h 50-2 h — Récap + checkpoint + devoir
- Moment fort : son app est EN LIGNE. Lui faire envoyer l'URL à un proche pour tester.
- **Devoir** : faire tester l'app par 2 personnes et noter leurs retours et bugs.

---

## Points de vigilance
- **Variables d'env** : la bêtise classique = oublier de les mettre dans Vercel → app cassée en prod. Vérifier ensemble.
- Supabase : s'assurer que les URL autorisées (redirect auth) incluent le domaine Vercel.
- Ne pas committer le `.env` (le hook protège, mais vérifier).
- **Économie Pro** : le déploiement Vercel ne consomme pas de quota Claude ; les corrections oui.

## Démo possible sur un vrai projet
Montrer une de tes apps en prod et son pipeline de déploiement.

## Critère de réussite
L'app est accessible par une URL publique et le parcours complet fonctionne en ligne.

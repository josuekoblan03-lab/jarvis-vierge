# Fiche formateur — S9 : MCP en pratique

**Objectif :** l'apprenant branche son premier MCP réel (Supabase) et le navigateur, comprend le rôle du `.env` et du coffre à secrets. À la fin, Claude peut parler à une vraie base de données.

**Pré-requis :** l'apprenant crée un compte Supabase (gratuit) AVANT la séance, ou on le fait au début.

---

## Déroulé (2 h)

### 0-10 min — Retour devoir
- Sa 3e commande. Rapide.

### 10-35 min — Concept : brancher Claude sur le monde réel
- Rappel S5 : un MCP = une prise. Aujourd'hui on branche vraiment.
- Supabase = une base de données PostgreSQL hébergée + auth, gratuite pour démarrer. Parfait pour son app.
- Les clés ne se collent JAMAIS dans le chat ni en dur dans le code. Elles vivent dans `.env` (ignoré par git) et dans le coffre `secrets/`.
- Workflow : `/ajouter-cle` pour stocker, `/generer-env` pour injecter dans un projet.
- Démo : montrer `.mcp.json` (les prises à placeholders) et `.env.example`.

### 35-50 min — Démo : remplir le .env et vérifier la connexion
- Montrer où récupérer le token Supabase (Dashboard > Account > Access Tokens) et le project-ref.
- Le mettre dans `.env`, relancer Claude Code, vérifier que le MCP Supabase se connecte (`/mcp`).

### 50 min-1 h 50 — Pratique
1. L'apprenant crée son projet Supabase (si pas fait).
2. Il stocke son token via `/ajouter-cle` (le formateur rappelle : jamais en clair dans le chat).
3. Il remplit son `.env` (Supabase + éventuellement GitHub).
4. Il relance Claude Code, tape `/mcp`, vérifie que Supabase est connecté.
5. Il demande à Claude : « liste les tables de ma base » (vide pour l'instant, c'est normal). Le lien est prouvé.
6. Il branche aussi le MCP navigateur (chrome-devtools) et demande à Claude d'ouvrir son app locale.
7. PROGRESS.md + commit (le `.env` ne sera PAS commité, montrer qu'il est gitignored).

### 1 h 50-2 h — Récap + checkpoint + devoir
- **Devoir** : lister (sur papier) les 2-3 tables dont son app aura besoin (ex. users, tâches, projets).

---

## Points de vigilance
- **Sécurité clés** : c'est LE moment où il peut faire une bêtise. Marteler : jamais de clé dans le chat, jamais en dur. Le hook secret-scanner le protège mais la discipline d'abord.
- Supabase gratuit : se met en pause après 7 jours d'inactivité (DNS qui échoue). Le prévenir : si « fetch failed », réveiller le projet dans le dashboard.
- **Économie Pro** : brancher un MCP ne coûte pas de quota en soi ; les requêtes via MCP, un peu. Rester sobre.

## Démo possible sur un vrai projet
Montrer un de tes projets branché à Supabase qui lit/écrit des données réelles.

## Critère de réussite
`/mcp` montre Supabase connecté, et Claude peut interroger la base.

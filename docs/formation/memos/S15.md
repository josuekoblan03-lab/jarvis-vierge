# Mémo S15 — Déploiement

## Ce que j'ai appris
- En local (`npm run dev`), seul moi vois l'app. **Déployer** = la rendre accessible par une URL publique.
- **Vercel** : hébergement fait pour Next.js, gratuit pour démarrer, se connecte à mon repo GitHub.
- Mes **variables d'environnement** doivent être recopiées dans les réglages Vercel (jamais dans le code, jamais commitées). L'app en prod lit celles de Vercel.
- **Preview** : chaque changement crée une URL de test avant la prod.

## Étapes
1. Pousser le code sur GitHub (repo privé).
2. Importer le projet dans Vercel.
3. Reporter mes variables d'env dans les réglages Vercel.
4. Déployer, ouvrir l'URL publique.
5. Tester le parcours complet en ligne (inscription, connexion, données).

## Pièges
- Oublier les variables d'env dans Vercel → app cassée en prod. À vérifier.
- Supabase : ajouter le domaine Vercel aux URL de redirection autorisées (auth).

# Mémo S3 — Continuité parfaite

## Ce que j'ai appris
- Une conversation Claude a une **limite**. Quand elle sature, je perds le contexte.
- La règle d'or : **tout ce qui a de la valeur va dans un fichier**, pas dans la conversation.
- Les 4 fichiers d'un projet :
  - **CLAUDE.md** — la constitution (stack, conventions, objectifs)
  - **PROGRESS.md** — où j'en suis
  - **DECISIONS.md** — pourquoi j'ai fait tel choix
  - **NEXT_SESSION.md** — le prompt pour repartir dans une conversation neuve
- `/nouveau-projet` crée tout ça AVANT de coder.
- `/reprendre` relit tout et me remet dans le bain en 30 secondes.

## Commandes à retenir
```
/nouveau-projet   # initialise un projet (structure + plan avant code)
/reprendre        # reprend un projet là où je l'avais laissé
npm run dev       # lance mon app en local pour la voir dans le navigateur
```

## Réflexe quota (Pro) — LE plus important
Quand je reviens, je **n'allonge pas** une vieille conversation : j'en ouvre une neuve et je tape `/reprendre`. Beaucoup moins cher, plus rapide.

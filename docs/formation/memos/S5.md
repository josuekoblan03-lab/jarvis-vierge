# Mémo S5 — C'est quoi tout ça ?

Analogie : **Claude Code = un employé très doué**. Voici ses outils et ses règles.

| Brique | C'est quoi | Analogie |
|---|---|---|
| **Commande** (`/prime`) | Un raccourci que je tape | Une macro |
| **Skill** | Une méthode de travail qu'il applique | Un mode d'emploi |
| **Agent** | Un collègue spécialiste à qui il délègue | Un expert qu'on appelle |
| **MCP** | Une prise vers un service extérieur (base, GitHub, navigateur) | Un câble USB vers le monde réel |
| **Hook** | Une règle automatique (ex. bloquer une clé) | Un garde-fou |
| **Plugin** | Un pack qui apporte skills+agents+commandes+MCP | Une extension à installer |

## Où ça vit dans mon Jarvis
```
.claude/commands/   → mes commandes
.claude/skills/     → mes skills
.claude/agents/     → mes agents
.claude/hooks/      → mes garde-fous
.mcp.json           → mes prises MCP
PLUGINS.md          → les plugins à installer
```

## Réflexe quota (Pro)
Déclencher un **agent** = une 2e conversation = ça consomme. Je l'utilise quand ça vaut vraiment le coup.

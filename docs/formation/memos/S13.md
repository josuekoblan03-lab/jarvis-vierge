# Mémo S13 — Agents et revue de code

## Ce que j'ai appris
- Un **agent** = un collègue spécialiste à qui Claude délègue.
  - `code-reviewer` : relit mon code (bugs, sécurité, qualité).
  - `debugger` + skill `systematic-debugging` : pour un bug, je ne tâtonne pas.
- La commande `/code-review` fait une revue cadrée.
- **Debug systématique** : reproduire → formuler une hypothèse → tester → isoler → corriger → vérifier. Jamais « j'essaie au hasard ».
- Face aux retours : je **trie** (bugs réels d'abord), je ne corrige pas tout aveuglément.

## Prompt type
> « Lance une revue de code (/code-review) sur ce fichier. Classe les problèmes par priorité et explique chacun avant de corriger. »

## Réflexe quota (Pro)
Une revue = une grosse conversation. Je la lance sur des morceaux ciblés.

## Mon devoir
Relancer une revue seul après mes corrections et vérifier que les points sont réglés.

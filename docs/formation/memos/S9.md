# Mémo S9 — MCP en pratique

## Ce que j'ai appris
- Un **MCP** branche Claude sur un service réel. Aujourd'hui : **Supabase** (base de données + auth, gratuit) et le **navigateur**.
- Mes clés ne vont **JAMAIS** dans le chat ni en dur dans le code. Elles vivent dans `.env` (ignoré par git) et dans le coffre `secrets/`.
- Workflow secrets : `/ajouter-cle` pour stocker, `/generer-env` pour injecter dans un projet.
- Je vérifie les connexions MCP avec `/mcp`.

## Étapes
1. Créer un projet Supabase (gratuit).
2. Récupérer le token (Dashboard > Account > Access Tokens).
3. `/ajouter-cle` pour le stocker (jamais en clair dans le chat).
4. Le mettre dans `.env`, relancer Claude Code.
5. `/mcp` → vérifier que Supabase est connecté.

## Pièges
- Supabase gratuit se met en **pause après 7 jours** sans activité → erreur « fetch failed ». Solution : réveiller le projet dans le dashboard.

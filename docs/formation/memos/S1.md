# Mémo S1 — Prise en main

## Ce que j'ai appris
- Le **terminal** : une fenêtre où je tape des commandes. Je lis toujours ce qui s'affiche.
- **Git** : l'historique de mon projet. 3 choses pour l'instant : dépôt, `git status`, commit (= photo sauvegardée).
- **Claude Code** : il ne fait pas que discuter, il agit (lit mes fichiers, en crée, en modifie).
- Mon **CONTEXT.md** et mon **CLAUDE.md** disent à Claude qui je suis et comment m'aider.

## Commandes à retenir
```
cd <dossier>      # se déplacer
ls                # lister ce qu'il y a ici
pwd               # où suis-je ?
git status        # où j'en suis côté sauvegarde
git add -A        # préparer tout à sauvegarder
git commit -m "message"   # sauvegarder une photo
/prime            # Claude charge mon contexte
```

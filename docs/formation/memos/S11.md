# Mémo S11 — Authentification

## Ce que j'ai appris
- **Authentification** = prouver qui je suis (login). **Autorisation** = ce que j'ai le droit de faire.
- **Supabase Auth** fournit tout clé en main (email/mot de passe). Je ne réinvente pas.
- Une **session** = l'app se souvient de moi après connexion.
- Une **route protégée** = une page visible seulement si je suis connecté.
- Chaque utilisateur ne doit voir **que ses données** (règles d'accès Supabase, RLS).

## Prompt type
> « Branche l'authentification Supabase (email/mot de passe) : crée les pages inscription et connexion, protège la page X (redirige si non connecté), et fais que chaque utilisateur ne voie que ses propres données. »

## Parcours à tester
Créer un compte → se connecter → voir ses données → se déconnecter.

## Réflexe quota (Pro)
L'auth est un bloc connu : un prompt bien cadré suffit, j'évite de tâtonner.

## Mon devoir
Tester les cas limites (mauvais mot de passe, email déjà pris) et noter le comportement.

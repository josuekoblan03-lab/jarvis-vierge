# Mémo S6 — Design et UI

## Ce que j'ai appris
- Claude ne devine pas mon goût : je **décris** l'ambiance (3 adjectifs), une référence (« comme Stripe »), les couleurs, la disposition.
- Les **skills de design** poussent vers un rendu pro : `frontend-design`, `premium-web-design`, `ui-design-system`, `tailwind-patterns`, `theme-factory`.
- **Tailwind** = des classes pour styler directement. Je n'ai pas à les connaître, Claude les écrit.
- Je fixe UNE ambiance et je garde la même sur toutes les pages (cohérence).

## Prompt type
> « Applique la skill frontend-design et restyle ma page d'accueil. Ambiance : sobre, moderne, professionnelle. Couleur principale : bleu nuit. Je veux un rendu épuré, pas générique. »

## Réflexe quota (Pro)
Je regroupe mes retouches visuelles dans un même échange au lieu d'un aller-retour par détail.

## Mon devoir
Styliser seul une page secondaire, en gardant la même ambiance.

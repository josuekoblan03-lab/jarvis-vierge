# Mémo S6 — Design avec Claude Design, puis code

## La méthode : design d'abord, code ensuite
Je ne code PAS l'interface à l'aveugle. Je la **dessine d'abord dans Claude Design**, je valide le visuel, PUIS je la transpose en code.

## Ce que j'ai appris
- **Claude Design** sert à maquetter l'interface rapidement. J'itère sur le visuel là, pas dans le code.
- Je décris l'ambiance (3 adjectifs), une référence (« comme Stripe »), les couleurs, la disposition. Claude ne devine pas mon goût.
- Une fois la maquette validée, **Claude Code la transpose** en Next.js + Tailwind.
- Les skills qui aident à transposer fidèlement : `frontend-design`, `ui-design-system`, `tailwind-patterns`, `theme-factory`.
- Je garde UNE ambiance cohérente sur toutes les pages.

## Le cycle
1. Décrire → **maquetter dans Claude Design**.
2. Ajuster le visuel (couleurs, disposition) jusqu'à ce que ça me plaise.
3. Demander à Claude Code de **transposer la maquette en code** Next.js + Tailwind.
4. Comparer le rendu codé à la maquette, corriger les écarts.

## Prompt type (transposition)
> « Voici ma maquette Claude Design pour la page d'accueil. Transpose-la en page Next.js + Tailwind, fidèle au visuel, en appliquant la skill frontend-design. »

## Réflexe quota (Pro)
Itérer le visuel dans Claude Design coûte moins que refaire du code 5 fois.

## Mon devoir
Maquetter seul une page secondaire dans Claude Design (même ambiance), sans encore la coder.

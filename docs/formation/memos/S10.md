# Mémo S10 — Base de données

## Ce que j'ai appris
- Une **table** = un tableur (lignes = enregistrements, colonnes = champs).
- Une **relation** = un lien entre tables (une tâche appartient à un utilisateur).
- **CRUD** = Créer, Lire, Mettre à jour, Supprimer. C'est 90% d'une app.
- La commande `/design-database-schema` aide à concevoir proprement.
- Je note mon schéma dans **DECISIONS.md** (c'est un choix structurant).

## Prompt type
> « Aide-moi à concevoir le schéma de mon app : [décrire les entités]. Puis crée la table X dans Supabase et une page qui liste ses lignes. »

## Pièges
- Supabase gratuit : une lecture peut être **tronquée à 1000 lignes** sans erreur. Pas grave à mon échelle.

## Réflexe quota (Pro)
Faire concevoir tout le schéma d'un coup, pas table par table sur 10 messages.

## Mon devoir
Ajouter la mise à jour OU la suppression (U ou D du CRUD) sur une entité, seul.
